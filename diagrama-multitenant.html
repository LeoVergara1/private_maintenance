🔄 Flujo de punta a punta

1. SuperAdmin (tú)Monitoreas todas las privadas. Si una no paga su suscripción → status: suspended y las rules le bloquean el acceso automáticamente.
2. Se vende solaCliente entra a /crear-privada → paga → se crea el doc condominiums → Function le pone claims de admin. Tú no tocas consola.
3. Admin invitaComparte inviteCode por WhatsApp. Vecino entra a /join/LOMAS-4X8K, login con Google, elige casa libre. Function valida unicidad (condoId+casa) y le da claims.
4. Operación diariaTodas las queries llevan where("condoId","==",claims.condoId). Las rules comparan token.condoId == resource.data.condoId. Imposible ver otra privada.

Firestore plano con condoId en cada doc · Storage en tenants/{condoId}/... · Seguridad por Custom Claims (0 lecturas extra en rules)
